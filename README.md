# Cracktivat0r
A utility for deleting setup.app from all types of iDevices (32bit or 64bit) running iOS 7.0 to iOS 10.2.1 to bypass the iCloud activation lock screen.

**Requirements :** A mac that has xcode tools installed with homebrew missing package manager installed too. And **Legacy iOS Kit** by _LukeZGD_.

_**[Notice : This tool has only been tested on iPhone 6 and 5S running (iOS 8.0) and (iOS 7.1.2). And platform macOS Big Sur, Intel macbook pro (mid-2014). Modern macs are not yet tested]**_

**Links :** 1) Homebrew Missing Package Manager; https://brew.sh/ and 2) Legacy iOS Kit; https://github.com/LukeZGD/Legacy-iOS-Kit.

For **Xcode Tools**, all you have to do is open a terminal window in your mac and type in this command, **xcode-select --install**

**Usage :** Use the Legacy iOS Kit tool to boot a SSH Ramdisk on your device. Then just open a terminal window and drag and drop the the **cracktivasi0n.sh** shell script on to the terminal.

There you go, the script will then automatically delete the setup.app from the root filesystem of your iDevice and auto reboot to the home screen.
